# UD Dummy Codebase v0.2

Educational C#/.NET-style dummy codebase for a future RAG assistant over UD-like logistics software.

## Purpose

This project models a simplified Unattended Delivery system with:

- Organisations and users
- Deliveries and delivery statuses
- Delivery spaces and smart boxes
- Smart locks and access rights
- Delivery assignment, space matching, alerts, and status updates

## Key business distinction

- Delivered: the deliverer has placed the delivery in the authorized box or space.
- Received: the receiver has retrieved the delivery.

## Recommended next step

Use this dummy codebase as source material for a RAG prototype that loads C# files, splits them into chunks, stores metadata, and answers architecture questions.
